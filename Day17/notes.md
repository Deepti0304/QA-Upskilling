Until you handle it, Selenium cannot interact with the webpage.

Frames

A frame is another HTML page inside the current page.

Selenium cannot access it directly.

Need to switch first.

Switch by Index
driver.switch_to.frame(0)
Switch by Name
driver.switch_to.frame("frame-top")
Switch by WebElement
frame = driver.find_element(By.TAG_NAME,"iframe")

driver.switch_to.frame(frame)

Switch to Parent Frame
driver.switch_to.parent_frame()

Moves one level up.

Switch to Default Content
driver.switch_to.default_content()

Moves back to the main page.

Always do this after working with frames.

Difference
Method	Meaning
